Kubernetes・Docker・Harbor・OpenShift・AWS の「よくある障害」を、本物そっくりのターミナルで解決するトレーニングゲーム。クリアするほどラックが稼働していきます。

はじめての方へ

                      遊び方

                      1. ミッションを選ぶトラック（Linux / Docker / Harbor / Kubernetes / OpenShift / AWS）ごとに順番に解放されます。
                      2. ブリーフィングを読む左側に状況と目標が出ます。目標は自動で判定され、達成するとチェックが付きます。
                      3. ターミナルで調査・修正本物と同じ書式のコマンドが使えます。help で一覧、Tab で補完、↑ で履歴。ファイル編集は vi ファイル名。
                      4. LIVE VIEW で状態を確認ラックの LED が緑＝正常、黄＝注意、赤＝異常。ラックにカーソルを合わせると詳細が見えます。
                      5. クリアの評価★3: ヒントなし＆目標時間内。ヒントを使うと ★ が減ります。獲得 XP でランクが上がり、データセンターのラックが稼働します。
                      6. 知識が足りないときはラーニングで分野ごとの学習問題（入門〜資格レベル）を。コマンドは コマンド辞典（どこでも Ctrl+K）で、名前でも「やりたいこと」でも探せます。ターミナルの apropos / man も同じ辞典を引きます。ミッション中に開いても環境はそのままです。

                      すべての操作はブラウザ内のシミュレーションで、実際のクラスタ・クラウド・ネットワークには一切接続しません。
